# Tugas 3 - Middleware

## Deskripsi

Proyek ini merupakan tugas pembelajaran pengembangan web menggunakan GitHub dan Vercel.

## Tujuan

* Memahami penggunaan GitHub untuk menyimpan kode program.
* Memahami penggunaan middleware dalam pengembangan aplikasi.
* Mempelajari proses deployment aplikasi menggunakan Vercel.

## Teknologi

* GitHub
* Vercel
* JavaScript

## Deployment

Proyek ini dibuat sebagai bagian dari tugas pembelajaran PPLG.
